Тема-срез по внутреннему стандарту WP Stack: BEM, ES-модули, панель настроек, формы и заявки через REST API.

== Description ==

WP Frame — базовая тема для кастомной вёрстки: сброс стилей и типографика, компонентные CSS-файлы, навигация, система форм с логированием заявок и уведомлениями.

== Installation ==

1. Скопируйте папку темы в `wp-content/themes/`.
2. В админке: Внешний вид → Темы → активируйте WP Frame.

== Frequently Asked Questions ==

= Нужны ли плагины? =

Для полей заявок в админке используется группа ACF (при установленном ACF Pro). Обязательных плагинов для работы меню и шаблонов нет.
